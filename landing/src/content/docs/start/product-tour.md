Walk the workspace once, then use [UI and panel reference](/docs/reference/layout) for control names, attach limits, and keyboard shortcuts.

## Open a workspace

Chat, Settings, and Marketplace are the three top-level views. In chat, the sidebar holds workspace tabs and the chat list. Use `Add workspace`, then New chat. Settings and Marketplace switch the whole main view; they are not chat panels.

A workspace selects the project folder. A chat selects persisted run history inside that workspace.

## Send a message

The composer is the Ask / Plan / Agent control, the model picker, and the prompt field. Attach files with +, mention workspace context with @, and run slash commands with /. [UI and panel reference](/docs/reference/layout) lists attach limits, @ mention options, and dictation.

A running or interrupted chat can stay in the sidebar. Opening an interrupted chat shows Continue, or resumes when Auto-resume interrupted runs is on.

## Review work in a panel

The dock rail opens Files, Browser, Terminal, Changes, Pull Request, and Plan. Show or hide a panel without ending the run. [Keyboard shortcuts](/docs/reference/shortcuts) lists the chords.
