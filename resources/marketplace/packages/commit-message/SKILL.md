# Commit message

## Instructions
1. Focus on why the change exists, not a file-by-file inventory.
2. Match the repository's recent commit message style and tense.
3. Keep the subject concise (~one line); add a short body only when needed.
4. Use intent verbs that fit the repo: add, fix, update, remove, refactor.
5. Do not mention tools, agents, or AI assistance.
6. Never invent changes that are not in the diff.
